# Radha Krishna Artistry – Catalogue Website

Static website (no build needed). Lavender theme, 219 designs, pricing, booking info and Instagram link.

## Vercel / GitHub Pages la deploy panna
1. Zip ah extract pannunga (index.html, data.js, images folder, README.md).
2. **Vercel:** Vercel dashboard -> Add New Project -> intha folder ah upload / GitHub repo import -> Deploy (Framework: Other, build command illa).
3. **GitHub Pages:** ella files um repo root la upload -> Settings -> Pages -> Branch: main / root.
4. Update varum pothu same names la files replace pannunga, live site update aagidum.
