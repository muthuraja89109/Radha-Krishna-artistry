# Radha Krishna Artistry – Catalogue Website

Static website (no build needed). Lavender theme, 208 designs, pricing, booking info and Instagram link.

## GitHub Pages la deploy panna
1. GitHub la new repository create pannunga (e.g. `rk-artistry`) – Public.
2. Intha zip ah extract pani, ulla irukura **ella files ayum** (index.html, data.js, images folder) repo la upload pannunga.
3. Repo -> Settings -> Pages -> Source: `Deploy from a branch` -> Branch: `main` / `(root)` -> Save.
4. 1-2 min la `https://<username>.github.io/rk-artistry/` la site live aagum.

## Edit panna
- Instagram link / prices / text: `index.html`
- Category ranges: `data.js`
